# iPhone Mobile Game Demo

This folder is a starter project space for a future iPhone mobile game that you can eventually distribute through TestFlight.

## Suggested next steps
- Choose an engine/framework (e.g., Swift + SpriteKit, Unity, or Godot iOS export).
- Create an Xcode project in this folder.
- Set up a Bundle Identifier and Apple Developer Team.
- Add basic gameplay prototype assets.
- Prepare signing/capabilities for iOS builds.

## TestFlight path (later)
1. Archive app in Xcode.
2. Upload build to App Store Connect.
3. Add internal testers in TestFlight.
4. Submit external testing review when ready.
